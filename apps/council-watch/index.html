            Ingestion Pipeline & Data Quality Principles
          


          

            

              

                1. Modular Connectors
              

              

                Custom ingestion modules per portal (Modern.gov, CMIS, Idox,
                Consultations). Strict respect for robots.txt, rate limits (1 req/2s), and
                conditional HTTP headers.
              

            


            

              

                2. Hash & Provenance Tracking
              

              

                Every PDF and document raw stream is hashed using SHA-256. Any modified
                published minutes trigger automated revision alerts in the "What Changed?"
                engine.
              

            


            

              

                3. pgvector & Confidence Scoring
              

              

                Text sections are embedded into 1536-dim vector spaces for hybrid semantic
                search. Derived entity matches carry confidence scores (e.g. 98%) with
                source citations.
